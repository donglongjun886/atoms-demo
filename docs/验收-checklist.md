# 验收走查 Checklist

> 主验收路径：Kimi Work 浏览器插件对部署链接自动执行演示脚本。本 checklist 是降级预案（插件不可用时人工走查），内容对齐 `docs/需求文档.md` 第 8 节。环境要求：桌面端、窗口宽度 ≥1280px、单标签页。

## 0. 准备

- [ ] 打开在线链接；在登录页点"重置 Demo 数据"，确认回到干净状态
- [ ] 5 个预设账号卡可见（Alice/Ben/Charlie/Diana/Eve）

## 1. 三分钟演示脚本

- [ ] Alice 一键登录成功，刷新页面仍保持登录
- [ ] 创建项目（名称 + 描述），项目卡片出现在"我的项目"，带阶段标签
- [ ] 进入共创空间：左聊天流、右 App Viewer、顶部阶段条六阶段可见
- [ ] Mike 问题卡出现，3 题一次答完后 Emma 产出计划卡
- [ ] 点"拒绝"：返回需求分析、Emma 重出方案；再点"批准"：进入架构设计
- [ ] 阶段条高亮跟随推进，负责 Agent 显示"工作中"，聊天流有交接发言
- [ ] 聊天输入"开始构建"与按钮效果一致（双入口）
- [ ] 构建动画：架构图模块逐个变色约 10 秒，代码文件同步逐个出现
- [ ] Alex 报各模块覆盖率，自动切到预览标签
- [ ] 预览应用：添加任务、勾选完成、筛选、删除全部可用
- [ ] 代码面板内容与预览功能一一对应
- [ ] "再看一遍"重播动画，消息流不追加、状态不变化

## 2. 多人协作

- [ ] Alice 邀请 Ben → 登出 → Ben 登录，项目列表顶部出现邀请卡片
- [ ] Ben 接受：入群消息出现、头像进协作者栏、项目进"参与的项目"
- [ ] Ben 发言、编辑方案并保存、发表评论
- [ ] 登出 → Alice 登录：看到 Ben 的消息、修改记录（按颜色区分）与评论

## 3. 健壮性（评委自由探索路径）

- [ ] 刷新页面：项目/消息/方案/评论/Workflow 状态/预览任务数据全部不丢
- [ ] 聊天输入无关内容（如"你是谁"）：Agent 兜底回复并提示可用指令
- [ ] 未接受邀请的账号直接改 URL 进项目：被重定向回项目列表
- [ ] 拒绝邀请后卡片消失，可再次被邀请
- [ ] 动画播放到一半刷新：恢复后回到"代码生成"入口待触发
- [ ] 页面上不存在任何点击无反应的按钮
